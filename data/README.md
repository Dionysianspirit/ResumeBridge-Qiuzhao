# 投递总表快照

| 文件 | 用途 |
| --- | --- |
| `catalog.json` | 扩展运行时读取 |
| `2026秋招投递总表-20260906.xlsx` | 同一份快照的 Excel，方便用表格软件打开 |

## 快照说明

- 日期：2026-09-06
- 来源：社区投递表（土豆投递表、互联派）
- 有效来源约 2,812 行，合并为约 2,788 条；过期约 489 条；本周优先 100 条

公开前已清空「挂钩提示」和「软岗分」。

「挂钩提示」不是岗位要求，而是「投这家时简历可以往哪段经历上靠」的个人备注，例如「可挂某个项目 / B 站」。这类内容只对原作者有用，公开时会去掉。公司、岗位、链接、档位、截止日期保留。

默认使用这份内置总表。也可以在插件里导入自己的 `catalog.json`；Excel 请先用 `scripts/import-catalog.py` 转换，导入时同样会清空上述个人字段。

## 使用注意

- 截止日期按原表计算，不保证官网仍在开放。
- 「招满为止」不会被改写成具体日期。
- 投递链接、内推标记和岗位列表请以官方招聘页为准。
- 这不是实时招聘数据库，也不会自动更新。

重新导入时请使用仓库根目录的 `scripts/import-catalog.py`，不要覆盖已经存在的 `catalog.json`。
